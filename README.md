# Jtodo - The todo application using WPF framework
A Todo application built using the **WPF (Windows Presentation Foundation)** framework, following the **MVVM (Model-View-ViewModel)** architectural pattern

## Key Features
- **Task Management:** Create, update, and delete daily tasks.
- **MVVM Architecture:** Clean separation between UI and business logic.
- **Data Binding:** Utilizing WPF's powerful binding system for real-time UI updates.
